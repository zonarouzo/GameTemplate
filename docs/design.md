# ゲーム企画書

> **【サンプル】** これはサンプルゲーム「ほしあつめ」の企画書です。初期設定のときに、あなたのゲームの内容に書き換えます。
> Claude はゲームを作る・直すときに、このファイルを読んでから作業します。

## 基本情報

| 項目 | 内容 |
|---|---|
| タイトル | ほしあつめ |
| ジャンル | カジュアル・反射神経 |
| 画面の向き | 縦（基準サイズ 360×640） |
| 操作 | タップ（パソコンではクリック） |
| 1回のプレイ時間 | 30秒 |
| 対象 | スマホで気軽に遊びたい人 |

## ルール

- 空から星が落ちてくる。タップすると1点。
- ときどき落ちてくる金の星は5点。速く落ちる。
- 30秒でおしまい。ハイスコアを保存する。

## 画面

1. タイトル画面（タップでスタート、ハイスコア表示）
2. プレイ画面（スコア・残り時間・一時停止ボタン）
3. 一時停止画面（タップで再開）
4. 結果画面（スコア・ハイスコア、タップでもう一度）

## 見た目・音

- 夜空の色の背景、パステルカラーの星
- 効果音はプログラムで作る短い音（素材ファイルなし）
