# 素材の出典（クレジット）

ゲームで使っている画像・音・フォントなどの素材と、その出典・ライセンスを記録します。
アプリとして公開するときに必要になるので、**素材を追加したら必ずここに書きます**。

| ファイル | 種類 | 作者・出典 | ライセンス・利用条件 | メモ |
|---|---|---|---|---|
| （なし） | | | | サンプルゲームは素材ファイルを使っていません |

## 書き方の例

| ファイル | 種類 | 作者・出典 | ライセンス・利用条件 | メモ |
|---|---|---|---|---|
| `www/assets/images/player.png` | 画像 | 自作 | — | |
| `www/assets/sounds/jump.mp3` | 効果音 | （サイト名・作者名・URL） | （例：商用利用可・クレジット不要） | 利用規約を確認した日付 |
