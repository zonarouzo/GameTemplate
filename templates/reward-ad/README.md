# リワード広告（仮組み用のハウス広告）

ゲームに「広告を見ると報酬がもらえる」機能（リワード広告）を作るときに使う部品です。
本物の広告（AdMob など）は、けんちくぶ！が Android アプリにするときに入れます。それまでは、この **チームのハウス広告** で仮組みします。

| ファイル | 内容 |
|---|---|
| `reward_ad.js` | リワード広告の部品（表示・5秒の待ち時間・× ボタン・戻るの確認） |
| `house_ad.jpg` | ハウス広告の画像（チーム「けんちくぶ」提供） |
| `demo.html` | 動作見本。GitHub Pages を設定していれば `https://ユーザー名.github.io/リポジトリ名/templates/reward-ad/demo.html` で試せます |

## 動き

- 画像をタップすると、`https://caitakenchikuclub.github.io/` を別の画面で開く
- 5秒たつと右上に × が出て、閉じられる（閉じると報酬あり）
- 5秒たつ前に「戻る」（Android の戻るボタン・ブラウザの戻る・Esc キー）を押すと、「今閉じると報酬はもらえません」と確認が出る
  - 「閉じる（報酬なし）」→ 報酬なしで終了／「広告にもどる」→ 広告の続きから（確認のあいだは待ち時間が止まる）
- 5秒たったあとの「戻る」は、× と同じ（報酬あり）
