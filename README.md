# GameTemplate — Claude と作るブラウザゲーム テンプレート

**Claude（Claude Pro）と GitHub を使って、ブラウザで遊べるゲームを作るためのテンプレートです。**

- パソコンに何かをインストールする必要はありません。ブラウザだけで作れます。
- プログラミングの知識は不要です。**Claude に日本語で「こんなゲームにしたい」と話しかけるだけ** で作り進められます。
- 作ったゲームは GitHub Pages で公開して、スマホやパソコンですぐ遊べます。
- あとから **Android アプリ** にしやすい作りになっています（アプリ化はチームの代表「けんちくぶ！」が行います）。

> 💾 作業内容は、Claude が作業のたびに自動でメインの保存場所（`main`）に反映します。プルリクエストなどの操作は不要です。

---

## はじめかた（概要）

1. このページ上部の「**Use this template**」→「**Create a new repository**」で、自分のリポジトリを作ります。
   - 公開範囲は **Public** で大丈夫です（GitHub Pages で無料公開するため）。
2. リポジトリの **Settings** → **Pages** で、「Deploy from a branch」「main」「/ (root)」を選んで **Save** します。
3. ブラウザで [Claude Code（claude.ai/code）](https://claude.ai/code) を開き、作ったリポジトリを選びます。
4. 「このリポジトリにあるファイルの一覧を教えて」と話しかけると、Claude が初期設定を提案してくれます。
   - **新しく作る**：作りたいゲームを聞かれるので、答えるだけで最初の形ができます。
   - **Claude のチャットなどで途中まで作ったゲームを移す**：そのゲームのコードを貼り付けると、Claude がこのリポジトリ用に整えて取り込みます。

数分後、`https://あなたのユーザー名.github.io/リポジトリ名/` でゲームが遊べるようになります。

---

## Claude への頼み方の例

| やりたいこと | 話しかけ方の例 |
|---|---|
| 機能を足す | 「ジャンプできるようにして」「敵を出して」 |
| 調整する | 「もう少し簡単にして」「星の落ちる速さを半分に」 |
| 見た目を変える | 「背景を森にして」「ボタンを大きく」 |
| 不具合を直す | 「スマホでタップが反応しないことがある」 |
| 企画を整理する | 「今のゲームの仕様を企画書にまとめて」 |
| 前の状態に戻す | 「さっきの変更を取り消して」 |

## フォルダの構成

```
├── www/            … ゲーム本体（アプリ化するときはこのフォルダが使われます）
├── docs/
│   ├── design.md   … ゲーム企画書
│   ├── credits.md  … 素材（画像・音）の出典
│   └── android.md  … Android アプリ化メモ（けんちくぶ！向け）
├── tools/check.js  … 動作確認スクリプト（Claude が使います）
└── CLAUDE.md       … Claude が守るルール
```

## Claude が守る主なルール

- 🧪 **保存する前に、ゲームをブラウザで開いてエラーがないか確かめます。**
- 📱 **スマホ・アプリで動く作り**にします（タッチ操作、画面サイズ、オフラインで動く）。
- 🎨 **素材は出典を記録**し、出典のわからない素材は使いません。
- 🛠 **大きな作り直しやファイルの削除は、先に相談**します。
- 💬 **作業が終わったら、遊べるアドレスと一緒に、わかりやすい日本語で報告**します。

## リワード広告（広告を見て報酬をもらう機能）

Claude に「リワード広告を付けて」と頼むと、本物の広告ではなく、チームのハウス広告（`templates/reward-ad/`）で仮組みします。
動きは `templates/reward-ad/demo.html` で試せます。本物の広告への差し替えは、けんちくぶ！がアプリ化のときに行います。

## Androidストアリリース対応（けんちくぶ！への引き渡し）

Google Play などでアプリとしてリリースしたいときだけ行います（必ず行うものではありません）。
リポジトリの **Settings** → **Danger Zone** → **Transfer** で、けんちくぶ！の GitHub アカウントに移管します。けんちくぶ！が1日以内に承認する必要があります。
変更の履歴もそのまま引き継がれ、元の持ち主は共同作業者として残ります。Android アプリ化の手順は `docs/android.md` を参照してください。

## サンプルについて

テンプレートには、例としてサンプルゲーム「ほしあつめ」（星をタップして集める30秒のゲーム）が入っています。
初期設定のときに、Claude があなたのゲームに置き換えます。

## ライセンス・その他

- このテンプレートを使って作ったゲームの権利は、作者（あなた）とチームにあります。
- サンプルゲームは自由に改変して使えます。
